From inclusion to sticky Brownian mass flow

Overview

For the inclusion process on a one-dimensional torus, the current AI proof gives convergence of the full mass process to the Le Jan–Raimond sticky Brownian mass flow. The scaling is \(N/L_N\to\rho>0\) and \(Nd_N\to\Theta>0\), with time acceleration \(N^2/d_N\). The initial state has a fixed finite bound on the number of isolated stacks. See the exact statement.
