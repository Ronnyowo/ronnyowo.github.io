# Review and changes

This repository is a public record of an AI proof.
Reports of gaps, counterexamples, and unclear steps are useful.

For a mathematical report, give these details:

1. The file and version.
2. The section, equation, or paragraph.
3. The precise claim that fails or needs support.
4. The missing hypothesis, argument, or counterexample.
5. The effect on each dependent claim.

Do not treat an AI audit as a human review.
Do not use the label “independently audited” for another instance of the same model family.

Proof and audit files in records/ are fixed records.
Add a new version when the mathematics changes.
Keep the old version and record the reason for the change.
Update the source manifest and reading guide when a new version is selected.

A human reader can edit the guide without changing a source proof.
Use short sentences.
Define technical terms.
Use standard LaTeX commands.
Use \(...\) for inline mathematics and \[...\] for displayed mathematics.

The current repository is a proof record and a guide.
The paper draft is a later task.
